# ESP32-S3 BadUSB & Wireless HID Bridge (Composite MSC + HID)

**MCU:** ESP32-S3-MINI-1-N8 | **Storage:** 4Gb SLC SD NAND | **Security:** ATECC608A | **License:** MIT

## 📌 О проекте
Проект представляет собой устройство на базе **ESP32-S3**, которое при подключении к ПК по USB определяется как **композитное устройство** (Mass Storage + HID Keyboard). Устройство имеет встроенный Wi-Fi веб-сервер для дистанционного управления вводом и доступом к файловой системе. 

Спроектирована кастомная печатная плата. Проект создан для демонстрации навыков проектирования аппаратного обеспечения, работы с высокоскоростными интерфейсами и интеграции аппаратной криптографии.

## 🚀 Ключевые возможности
- **Композитный USB-девайс**: Одновременная работа Mass Storage Class (флешка) и Human Interface Device (клавиатура).
- **Web-интерфейс**: Удаленное управление через Wi-Fi (потоковый ввод текста, эмуляция горячих клавиш, функциональных клавиш).
- **Аппаратное шифрование**: Криптографический сопроцессор **ATECC608A** для генерации ключей, AES-шифрования и защиты потоков данных.
- **Кастомная печатная плата**: Спроектирована в EasyEDA с учетом требований по целостности питания.
- **Энергонезависимая память**: 4 Гбит (512 МБ) SLC NAND через SPI.

## 🛠 Аппаратное обеспечение (Hardware)

| Компонент | Модель / Характеристика | Назначение |
| :--- | :--- | :--- |

| **Storage** | MKDV4GCL-ABF (4Gbit SLC SD NAND) | Хранение файлов / образа MSC |

## 💻 Программное обеспечение (Software)
- **Среда разработки**: Arduino IDE (ядро ESP32).
- **USB-стек**: TinyUSB (композитный дескриптор).
- **Веб-сервер**: Асинхронный HTTP-сервер (ESPAsyncWebServer).
- **Файловая система**: FATFS / LittleFS для работы с SD NAND.
- **Библиотеки криптографии**: CryptoAuthLib (Microchip) для ATECC608A.

## ⚡️ Производительность и ограничения интерфейсов

### 1. USB 2.0 Full-Speed (ESP32-S3)
ESP32-S3 имеет встроенный USB-OTG контроллер, поддерживающий только режим **Full-Speed (12 Мбит/с)**.
- **Теоретический предел шины**: 12 Мбит/с (1.5 МБ/с). Из-за накладных расходов (пакеты, CRC, служебные транзакции) полезная нагрузка ниже.
- **Реалистичный потолок (Bulk)**: ~**9.1 Мбит/с** (≈ 1.14 МБ/с) при идеальных условиях и оптимизированном стеке.
- **Практическая скорость (MSC)**: В тестах реальная скорость записи/чтения файлов через MSC часто составляет **300–600 КБ/с** из-за задержек файловой системы и NAND. Это нормально для Full-Speed и ограничивает максимальный поток.

### 2. Интерфейс SD NAND (SPI)
Чип MKDV4GCL-ABF поддерживает **SPI-режим** с максимальной тактовой частотой **50 МГц**.
- **Теоретическая пропускная способность SPI**: 50 МГц × 1 бит = **50 Мбит/с** (≈ 6.25 МБ/с). 
- **Практическая частота на ESP32-S3**: Контроллер способен выдавать до 80 МГц, но чип SD NAND ограничен 50 МГц. При маршрутизации через GPIO Matrix частота обычно настраивается на 40 МГц для стабильности.
- **Эффективная скорость с учетом USB**: Поскольку USB Full-Speed является узким местом (макс. ~1.14 МБ/с), скорость SPI (6.25 МБ/с) **не является бутылочным горлышком**. SD-карта будет простаивать, ожидая передачи данных по USB. Таким образом, эффективная скорость чтения/записи файлов будет определяться именно USB-интерфейсом и программным стеком TinyUSB.

## 🔐 Безопасность и криптография
В проекте заложена возможность потокового шифрования файлов.
- **ATECC608A** поддерживает **AES-128** (аппаратный движок), а также ECDH для безопасного обмена ключами.
- Шифрование может применяться как к данным на SD-карте (Data-at-Rest), так и к потокам, передаваемым через веб-интерфейс.
- Для потокового шифрования используется буферизация, так как ATECC608A имеет ограничения по размеру блока (кратно 16 байтам) и работает через I2C.

## 🖥 Использование
1. Подключите устройство к ПК через USB.
2. В диспетчере устройств появятся два интерфейса: **Съемный диск** и **Клавиатура**.
3. Подключитесь к Wi-Fi сети, которую поднимает ESP32-S3.
4. Откройте веб-браузер и перейдите по IP-адресу устройства.
5. В веб-интерфейсе доступны:
   - Поле для потокового ввода текста.
   - Кнопки эмуляции горячих клавиш (`Ctrl+C`, `Alt+Tab` и т.д.).
   - Управление файлами на встроенной флеш-памяти.
